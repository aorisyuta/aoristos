Sodpion

oxpio ・ 高校2年生。数学やプログラミング、電子工作など、興味のある分野でいろいろなものづくりを楽しんでいます。

活動・所属

学校では電気工学部（部長）と物理部に所属しているほか、筋トレ部を設立して活動しています。

学生科学団体「Aoristos」では、運営や Web サイトの管理などに携わっています。

数学・競技科学

競技数学が好きで、JMO（日本数学オリンピック）や OMC などのコンテストに向けて勉強しています。

最近は特に、整数論と幾何学の問題に興味を持っています。

プログラミング・Web 制作

好きな言語は Rust と Python です。普段は Fedora Linux を使っています。

Python でオーディオ処理（Colab でのボーカル分離プログラムなど）を試したり、団体の Web サイト用に LaTeX 対応のブログシステムを作ったりしながら、少しずつ技術を勉強中です。

電子工作

アナログ回路が好きで、日本橋でパーツを集めて、ディスクリートのヘッドホンアンプやオペアンプなどを自作しています。

Raspberry Pi や ESP32 などのマイコンを使った工作にも取り組んでいます。

趣味・その他

DTM（GarageBand など）での楽曲制作、SF 小説の執筆、短歌、人工言語など、理数系に限らずいろいろなものを作るのが好きです。
